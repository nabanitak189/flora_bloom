# Flora Bloom

Flora Bloom is a computer vision-based project that enables real-time control of a virtual flower using hand gestures captured through a camera.

## Overview

This system tracks both hands and maps their movements to control different aspects of the flower. The right hand adjusts the glow intensity, while the left hand controls the bloom and width, creating an intuitive and touchless interaction.
Users can also select different colors for the flower and choose between two types of flowers, creating a customizable and touchless interactive experience
## Features

* Gesture-based control using a camera
* Independent control of glow and bloom
* Real-time visual feedback
* Smooth interaction without physical input
